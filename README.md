# MiMo V2.6 × Karpathy｜模型训练入门调研与学习路线

**资料快照：2026-09-22。**面向有计算机编程背景、尚未系统学习机器学习、深度学习和 AI Infra 的学习者。

本仓库整理 MiMo 官方公开资料、Karpathy 教学项目及其差异，并给出从第一次小模型训练到理解 Agent/RL 工程的动手路线。它是**调研与学习方案**，不是已经复现 MiMo 训练结果的代码仓库。

## 先看结论

**能学，也适合亲手经历一次真实训练；但不建议把 MiMo 9B 的完整 RL 作为第一课。**

MiMo 发布的 `MiMo-V2.6-Distill-Qwen-9B` 是已经完成监督微调的 Qwen 派生模型，适合作为后训练研究起点，不是从零训练教程。Karpathy 的小 GPT 项目更适合先理解参数怎样学习；再用 nanochat 连接预训练、SFT、评测和聊天，最后进入 MiMo 的任务、轨迹、奖励与训练工程。[9B 官方模型卡](https://huggingface.co/XiaomiMiMo/MiMo-V2.6-Distill-Qwen-9B)

你提到的“2024 年左右的 GPT 教程”最可能是 **build-nanogpt**，但仅凭描述不能唯一确定；本仓库同时辨认了 ng-video-lecture、nanoGPT、llm.c 和较新的 nanochat，避免混用它们的目标与算力要求。

## 推荐主线

```text
必要的 Python / 数学 / 张量基础
                ↓
      micrograd → makemore
                ↓
ng-video-lecture：从随机参数训练一个小 GPT
                ↓
保存 + 重新加载 + 验证集 + 单变量实验
                ↓
   已完成第一套真实的预训练闭环
                ↓
按兴趣分支：
  模型实现/效率 → build-nanogpt → llm.c（选读）
  聊天/RL      → nanochat 小规模流程 → MiMo 任务与轨迹
                                      ↓
                          简单奖励实验 → 9B RL（条件成熟后）
```

MiMo 的文章和模型卡可以从第一阶段就穿插阅读。**不需要为了开始而先学完整套 AI 课程，也不需要把所有 Karpathy 仓库逐个做完。**

## 这个方案所说的“完整流程”

**第一层：小规模预训练，推荐必做。**

```text
文本 → 编码 → 构造输入/目标 → 随机初始化
     → 预测 → loss → 反向传播 → 参数更新
     → 独立验证 → 保存模型 → 新进程加载 → 生成
```

**第二层：后训练与使用，进阶选做。**在已有模型上做 SFT 或简单奖励训练，再评估与使用。这里会学习训练目标、聊天格式和奖励的区别。nanochat 当前默认 speedrun/CPU 脚本不自动包含 RL，RL 入口需单独理解和执行。[speedrun](https://github.com/karpathy/nanochat/blob/master/runs/speedrun.sh) · [RL 脚本](https://github.com/karpathy/nanochat/blob/master/scripts/chat_rl.py)

**第三层：MiMo 级工业训练，不设为入门目标。**只有对齐模型、数据、环境、算法、部署与评测，才谈对应范围的复现；不能把下载权重、调用 API 或换成 LoRA 的教学实验称为完整工业复现。

## 投入与收获

最小主线估算为 **24–37 小时主动学习**；每周 6 小时约 4–7 周。这是本仓库的学习规划估算，**不是视频总长、机器训练时间或完成保证**。实际设备、下载与排错会影响日历时间。

完成后应能解释一次参数更新，独立保存与读取自己的模型，区分训练和验证，设计并解释一个对照实验。再进入 MiMo，学习重点会转向任务环境、工具调用、轨迹采集、评分和参数优化之间的连接。

入门可以先用 CPU 或已有消费级 GPU，不先买设备、不先租集群。9B 的 BF16 裸权重约为 18 GB 量级，训练还要额外考虑梯度、优化器与激活；不能由“量化推理能跑”推导“完整 RL 能跑”。详细假设和预算方法见 [05](docs/05-resources-and-costs.md)。

## 仓库使用方式

本仓库保存研究笔记、学习方案与经清理的实验摘要。实际教学代码可以放在相邻目录，避免嵌套仓库混乱。`.gitignore` 已排除常见密钥文件、虚拟环境、大模型权重和原始运行目录；提交前仍需人工检查日志是否含隐私或凭证。

不要让 AI 替你默默改完整个训练项目。先写自己的预测与解释，再让它给提示、查错和审阅；最后用自己的运行结果验证。

**核心目标：不只是让命令跑完，而是知道模型在学什么、参数为什么改变，以及凭什么认为它学到了东西。**
