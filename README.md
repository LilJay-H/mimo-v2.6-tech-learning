# MiMo V2.6 技术学习调研

面向有计算机专业背景、尚未系统学习机器学习和深度学习的学习者，整理 MiMo 官方公开资料与 Karpathy 教学项目，并设计可动手完成的小模型训练学习路径。

## 调研范围

- 核实 MiMo V2.6 相关发布、技术报告、模型与训练代码的公开范围。
- 识别小模型训练仓库与 Karpathy 对应教学项目，区分定位、学习收获和计算资源要求。
- 给出从基础知识到小规模训练实验的分阶段学习方案，区分预训练、后训练与完整工业训练流程。
- 为事实提供可追溯的原始来源，为学习时长和资源预算注明估算前提。
